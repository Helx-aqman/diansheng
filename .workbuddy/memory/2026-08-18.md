## App 工程运行排障（HBuilderX 运行到浏览器）
- 公司安保禁真机基座调试 → 改用 HBuilderX「运行到浏览器」(H5)。但本机无 Android system-image、无 AVD，模拟器也跑不了。
- **关键坑**：uni-app(Vue3) 在 HBuilderX 里本质是 **vite 工程**，必须含 `index.html`(根,引 `/src/main.js`)+`vite.config.js`(装 `@dcloudio/vite-plugin-uni`)+源码放 `src/`，且 `package.json` 带 vite 依赖与 `dev:h5` 脚本。缺任一项 HBuilderX 判定不了工程类型 → 报「根目录缺少 index.html」或「浏览器运行尚不支持此种类型文件」。
- 修复动作：把 App.vue/main.js/uni.scss/components/pages/store/mock/utils 移入 `src/`；根目录补 `index.html`、`vite.config.js`(`@`→src 别名)、恢复 vite 版 `package.json`；删 `.hbuilderx` 强制重新识别。JSON 与 vite.config.js 语法已校验通过。
- 运行要点：**右键项目根目录**（非单个文件）→ 运行 → 运行到浏览器 → Chrome；HBuilderX 用自带编译器，一般不需 `npm install`。若提示缺模块，则需在 app/ 下 `npm install`（受网络/安保限制，可能需公司 npm 镜像）。
