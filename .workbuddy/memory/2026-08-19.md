## uni.scss 全局样式未生效导致"页面没样式"（同日上午）
- **现象**：H5 预览出来"没有图片和样式"——其实是整页失去主题色/背景/边框，只剩裸布局。
- **根因（关键）**：`@dcloudio/vite-plugin-uni` 只把 `uni.scss` 内容通过 `preprocessorOptions.scss.additionalData` 注入到 **`lang="scss"`** 的样式编译里；而各页面用的是**纯 `lang="css"` 的 `<style scoped>`**，所以 `uni.scss` 里的 `:root{--primary...}` 全局 CSS 变量从没被加载 → 所有 `var()` 全失效。另外 `uni.scss` 文件本身**不会被当作全局 CSS 自动加载**，必须靠组件用 scss 或显式 import。
- **修复（最小改动）**：
  1. `src/App.vue` 的 `<script setup>` 里加 `import './uni.scss'`（全局变量/通用类/主题切换只加载一次）；
  2. `src/uni.scss` 的 `page {` 改为 `page, uni-page-body, body {`——因为 H5 没有 `page` 元素，否则页面根背景仍是白的。
- **验证**：`App.vue` 编译模块出现 `import "/src/uni.scss"`，`uni.scss` 模块 `:root`/`--primary`/`updateStyle`/`data-theme`/`uni-page-body` 计数正常 → 全局变量已注入入口。刷新预览即生效。
- **结论**：改完 `App.vue` 一处 + `uni.scss` 选择器一处即修复；无需把 16 页面+4 组件全改 `lang="scss"`。
- **图片说明（已解决）**：原型 `covers/Chinese_classical_mythology_bo_2026-08-18T04-15-12.png` 即西游记示例封面。已复用：复制到 `app/static/xiyouji_cover.png`（HTTP 200 可访问）。`BookCard.vue` 封面改为按 `cover` prop 决定：**有封面（西游记）用 `<image src="/static/xiyouji_cover.png">`，无封面的占位书回退到"首字渐变"占位**（`.cv.ph`）。`home.vue` 给 main 传 `cover`，占位书不传。刷新预览即有真实封面图，占位书为差异性渐变首字。
